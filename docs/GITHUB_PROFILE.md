Trakya Üniversitesi **Mobil Teknolojileri (Ön Lisans)** bölümünden 2026 yılında **3.24 / 4.00** not ortalamasıyla mezun oldum. Yazılım geliştirici olarak Flutter ve Dart ile mobil uygulamalar, JavaScript ile web projeleri geliştiriyorum. Kullanıcı ihtiyaçlarını anlaşılır arayüzlere dönüştürmeye, verileri kalıcı saklamaya ve geliştirdiğim kodu test etmeye odaklanıyorum.

**Yazılım geliştirme alanında iş fırsatlarına açığım.** Öğrenmeye açık, sorumluluk sahibi ve ekip içinde katkı sunmaya istekli bir geliştiriciyim.

## Kullandığım teknolojiler

| Alan | Teknolojiler |
| --- | --- |
| Mobil | Flutter, Dart, Android Studio, Material 3 |
| Web | HTML5, CSS3, JavaScript |
| Veri | SQLite, SharedPreferences, localStorage, JSON |
| Geliştirme ve doğrulama | Git, GitHub, GitHub Actions, Flutter testleri |

**Kod kalitesi:** Model, veritabanı ve ekran kodları ayrı dosyalarda; mobil projelerde gerçek SQLite testleri, OkuTrack’ta 22 davranış testi bulunuyor. Analiz ve testler GitHub Actions üzerinde çalışıyor.

**Diğer çalışmalarım:** [Kotlin hesap makinesi](https://github.com/alidanis61615/index/tree/main/projects/android-calculator), [C# / Unity 2D platform oyunu](https://github.com/alidanis61615/index/tree/main/projects/unity-2d-platformer), Java temelleri ve WordPress.
