# Android Hesap Makinesi

Kotlin ve Android Studio kullanılarak geliştirilen modern, mobil uyumlu bir hesap makinesi uygulaması.

## Özellikler

- Toplama, çıkarma, çarpma ve bölme
- Ondalık sayı desteği
- Yüzde hesaplama
- Pozitif/negatif sayı değiştirme
- Sıfıra bölme kontrolü
- Farklı ekran boyutlarına uyumlu arayüz
- Hesaplama mantığı için birim testleri

## Kullanılan Teknolojiler

- Kotlin
- Android Studio
- XML arayüz tasarımı
- Material Design 3
- Gradle
- JUnit

## Proje Yapısı

- `MainActivity.kt`: Arayüz etkileşimleri
- `CalculatorEngine.kt`: Hesaplama ve durum yönetimi
- `activity_main.xml`: Uygulama arayüzü
- `CalculatorEngineTest.kt`: Temel işlem testleri

## Çalıştırma

1. Projeyi Android Studio ile açın.
2. Gradle senkronizasyonunun tamamlanmasını bekleyin.
3. Bir emülatör veya Android cihaz seçin.
4. **Run** düğmesine basın.
